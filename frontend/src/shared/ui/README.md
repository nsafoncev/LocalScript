# Shared UI

## Описание функционала

Слой `shared/ui` содержит переиспользуемые визуальные примитивы приложения, включая новый набор компонентов для сообщений AI-чата: `CodeBlock`, `CopyIconButton` и `MessageActions`.

## Цель

- держать copy UI и code block вне бизнес-логики чата
- переиспользовать одни и те же контролы для сообщений пользователя и ассистента
- обеспечить единый внешний вид в светлой и тёмной теме

## FSD-слой

`shared/ui`

## Структура

- `CodeBlock.tsx` — code-only рендер с copy-кнопкой для кода
- `CopyIconButton.tsx` — компактная иконка-кнопка копирования
- `MessageActions.tsx` — нижняя панель действий сообщения
- `message-content/` — markdown-рендер текста сообщения

## Пример использования

```tsx
<MessageActions
  copyLabel="Скопировать сообщение"
  statusText={statusText}
  theme={theme}
  onCopy={handleCopy}
/>
```

## Ограничения

- компоненты слоя `shared/ui` не содержат бизнес-логики чата
- определение, что сообщение является кодом, происходит вне этого слоя
