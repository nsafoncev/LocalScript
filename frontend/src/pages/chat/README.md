# Chat Page

## Описание функционала

`pages/chat` координирует workspace AI-чата: начальную загрузку истории, выбор активного чата, создание новой локальной сессии и отправку сообщений.

## Цель

Сделать старт приложения пустым и честным: без дефолтного чата и без автосоздания диалога при первом открытии.

## FSD-слой

`pages/chat`

## Структура

- `model/use-chat-workspace.ts` — orchestration логика страницы
- `ui/ChatPage.tsx` — связывает page-level model и layout

## Пример использования

```ts
const {
  chats,
  activeChatId,
  messages,
  createChat,
  sendMessage,
} = useChatWorkspace()
```

## Ограничения

- стартовая история чатов пустая
- новый чат создаётся только по кнопке `Новый чат` или в момент первой отправки сообщения
- backend не хранит историю, поэтому список чатов остаётся локальным состоянием frontend
